# PRD — 나만의 퀴즈 게임 (코디세이 파이썬 과제)

- 작성: 2026-11-10
- 근거: 코디세이 미션 「컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기」 원문
- 저장소: https://github.com/Frost0313z/codyssey_python_quiz_game

---

## 1. 목적

터미널에서 동작하는 퀴즈 게임을 **처음부터 끝까지 직접** 만들면서 아래를 몸으로 익힌다.

- Python 기초 — 변수, 자료형(int · str · bool · list · dict), 조건문, 반복문, 함수
- 클래스와 객체 — `__init__`, `self`, 속성과 메서드
- 파일 입출력 — JSON 저장 · 불러오기, try/except 오류 처리
- Git — init · add · commit · push · pull · checkout · clone, 브랜치 생성과 병합

**학습 규칙:** 코드와 git 명령은 학습자가 직접 쓴다. Claude 는 설명 · 힌트 · 검토만 한다.

## 2. 범위

| 포함 | 제외 |
|---|---|
| 메뉴 · 퀴즈 풀기 · 추가 · 목록 · 점수 확인 · 종료 | 외부 라이브러리 (표준 라이브러리만 허용) |
| `state.json` 저장 · 불러오기 | GUI · 웹 화면 |
| Git 기록 (커밋 10개 이상, 브랜치 병합, clone · pull) | 보너스 과제 (필수를 다 끝낸 뒤 판단 — 7장 D8) |

## 3. 요구

각 요구의 「완료 조건」이 모두 맞아야 끝난 것으로 본다. 시험 방법은 8장.

### R1. Git 저장소 설정

- GitHub 공개 저장소, 로컬 저장소, `.gitignore`, `README.md`
- 완료 조건: 첫 커밋이 GitHub 에 올라가 있다.

### R2. 메뉴

- 실행하면 메뉴(1 퀴즈 풀기 · 2 퀴즈 추가 · 3 퀴즈 목록 · 4 점수 확인 · 5 종료)를 출력한다.
- 번호를 골라 기능을 실행하고, 끝나면 메뉴로 돌아온다.
- 5 를 고르면 종료한다.
- 완료 조건: 잘못된 입력에도 프로그램이 죽지 않고 메뉴로 돌아온다 (R3 기준).

### R3. 공통 입력 · 예외 처리 (숫자를 입력받는 모든 곳)

| 경우 | 동작 |
|---|---|
| 앞뒤 공백 (` 1 `) | 공백을 지운 뒤 처리 |
| 숫자 아님 (`abc`) | 안내 메시지 → 다시 입력 |
| 범위 밖 (메뉴 `9`, 정답 `0`) | 안내 메시지 → 다시 입력 |
| 빈 입력 (그냥 Enter) | 안내 메시지 → 다시 입력 |
| Ctrl+C (`KeyboardInterrupt`) · 입력 끝 (`EOFError`) | 안내 메시지 → 저장 가능한 것은 저장 → 정상 종료 |

- 완료 조건: 위 다섯 경우 모두 오류 메시지(Traceback) 없이 동작한다.

### R4. Quiz 클래스

- 속성: `question`(문제) · `choices`(선택지 4개) · `answer`(정답 번호 1~4)
- 메서드: 퀴즈 출력, 정답 확인 — 그 밖에 필요한 것
- 완료 조건: `Quiz(...)` 로 만든 객체가 스스로를 출력하고, 입력한 번호가 정답인지 판정한다.

### R5. 기본 퀴즈 데이터

- 학습자가 고른 주제(7장 D1)로 퀴즈 **5개 이상**, 각각 문제 · 선택지 4개 · 정답
- `Quiz` 클래스의 인스턴스로 만든다.
- 완료 조건: `state.json` 이 없을 때 이 5개 이상이 그대로 쓰인다.

### R6. 퀴즈 풀기 (브랜치에서 작업)

- 저장된 퀴즈를 차례로 출제하고, 정답 번호를 입력받아(R3 기준) 정답 · 오답을 알려 준다.
- 다 풀면 결과(맞힌 개수 · 점수)를 보여 준다.
- 퀴즈가 0개면 안내 메시지를 보여 주고 메뉴로 돌아간다.
- 완료 조건: `main` 이 아닌 브랜치에서 작업해 커밋하고, `main` 으로 병합한 기록이 있다.

### R7. 퀴즈 추가

- 문제, 선택지 4개, 정답 번호(1~4)를 입력받는다.
- 정답 번호는 R3 기준을 따른다. 문제 · 선택지가 빈 글자이면 다시 입력받는다 (7장 D6).
- 추가한 퀴즈는 바로 `state.json` 에 저장한다.
- 완료 조건: 추가 → 종료 → 다시 실행했을 때 추가한 퀴즈가 남아 있다.

### R8. 퀴즈 목록

- 등록된 퀴즈의 개수와 문제를 번호와 함께 보여 준다.
- 퀴즈가 0개면 안내 메시지를 보여 준다.
- 완료 조건: 기본 퀴즈와 추가한 퀴즈가 모두 목록에 나온다.

### R9. 점수 확인

- 최고 점수를 보여 준다. 한 번도 풀지 않았으면 "아직 기록 없음"이라고 안내한다.
- 퀴즈를 다 풀 때마다 최고 점수와 비교해 더 높으면 갱신하고 `state.json` 에 저장한다.
- 완료 조건: 최고 점수가 재실행 뒤에도 남아 있다.

### R10. QuizGame 클래스

- 게임 전체를 관리한다. 속성: 퀴즈 목록 · 최고 점수 등. 메서드: 메뉴 표시 · 풀기 · 추가 · 목록 · 점수 · 저장 · 불러오기 등.
- 완료 조건: 클래스가 2개 이상(`Quiz`, `QuizGame`)이고, 기능별로 메서드가 나뉘어 있다. 한 함수에 모든 코드를 몰아넣지 않는다.

### R11. 파일 저장 · 불러오기

- 프로젝트 루트의 `state.json` 에 UTF-8 로 저장한다. 스키마는 4장.
- 파일이 없으면(첫 실행) 기본 퀴즈를 쓴다.
- 파일이 손상됐거나 읽기 · 쓰기 오류가 나면 try/except 로 잡고, 안내 메시지를 보여 준 뒤 기본 퀴즈로 복구한다 (7장 D4).
- 완료 조건: 8장의 파일 시험이 모두 통과한다.

### R12. README

- 프로젝트 개요 · 퀴즈 주제와 선정 이유 · 실행 방법 · 기능 목록 · 파일 구조 · 데이터 파일 설명(`state.json` 경로 · 역할 · 스키마)
- 완료 조건: 여섯 항목이 모두 있고, 최종 push 가 되어 있다.

### R13. clone · pull 실습

1. 저장소를 다른 폴더에 clone 한다.
2. 그 폴더에서 README 에 한 줄을 추가하고 commit → push 한다.
3. 원래 폴더에서 pull 한다.
4. 추가한 줄이 원래 폴더에 보이는지 확인한다.

- 완료 조건: 네 단계의 터미널 출력이 있다.

### R14. 제약

- Python 3.10 이상 (지금 설치된 버전: 3.14.6, 2026-11-10 확인)
- 외부 라이브러리 없이 표준 라이브러리만 쓴다.
- 커밋 10개 이상. 기능 단위로 커밋하고 메시지에 내용을 적는다 (`Feat:` · `Fix:` · `Docs:` · `Refactor:`).
- git 명령 7종(init · add · commit · push · pull · checkout · clone)을 각각 한 번 이상 쓴다.

## 4. 데이터 명세 — `state.json`

- 위치: 프로젝트 루트 (`main.py` 와 같은 폴더)
- 인코딩: UTF-8
- 역할: 퀴즈 목록과 최고 점수를 프로그램 종료 뒤에도 남긴다.

```json
{
    "quizzes": [
        {
            "question": "문제",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 2
        }
    ],
    "best_score": null
}
```

| 키 | 형태 | 규칙 |
|---|---|---|
| `quizzes` | 목록(list) | 각 항목은 아래 세 키를 가진 사전(dict). 비어 있어도 된다 (7장 D7) |
| `question` | 문자열(str) | 빈 글자가 아니다 |
| `choices` | 문자열 4개 목록 | 정확히 4개 |
| `answer` | 정수(int) | 1~4 |
| `best_score` | 정수 또는 `null` | 0~100 점. 한 번도 안 풀었으면 `null` (7장 D2 · D3) |

이 규칙에 맞지 않는 파일은 「손상된 파일」로 다룬다.

## 5. 화면

문구와 꾸밈은 자유. 미션 원문 「8. 결과 예시」를 참고한다. 꼭 있어야 하는 것만 적는다.

- 시작할 때 불러온 결과를 알린다 — 예: "저장된 데이터를 불러왔습니다 (퀴즈 6개, 최고점수 80점)"
- 풀기 결과에 맞힌 개수와 점수, 최고 점수를 갱신했는지 여부가 나온다.
- 잘못된 입력에는 허용 범위를 알려 준다 — 예: "1-5 사이의 숫자를 입력하세요"
